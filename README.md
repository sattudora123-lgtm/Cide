# CIDE

### One Host AI. Multiple Agents. One Unified Result.

CIDE is a multi-AI orchestration platform designed to bring multiple AI agents and browser-based AI models into one centralized workspace.

Instead of manually switching between AI tools, users submit a task to CIDE's Host AI, which plans, distributes, monitors, and coordinates work across multiple AI systems.

## Vision

Build a centralized platform where multiple AI systems can collaborate on complex tasks instead of relying on a single AI model.

CIDE acts as the manager of an AI workforce.

## How It Works

1. **User Input** — Submit a task through text or voice.
2. **Host AI** — Understands the request and creates a workflow.
3. **Task Distribution** — Assigns subtasks to suitable AI agents and models.
4. **Parallel Execution** — Multiple AI systems work simultaneously.
5. **Progress Monitoring** — Displays individual agent progress and status.
6. **Evaluation** — Host AI reviews and compares outputs.
7. **Final Result** — Combines useful results into one unified response.

## Core Features (Planned)

- Central Host AI orchestrator.
- Multiple AI agents working simultaneously.

## Example Workflow

User request:

"Build me a modern e-commerce website."

Possible task distribution:

| AI System | Responsibility |
|---|---|
| Claude Code | Backend development |
| ChatGPT | Architecture and planning |
| Gemini | UI/UX research |
| OpenCode | Additional development |
| Host AI | Coordination and evaluation |

The actual assignments depend on available integrations and agent capabilities.

## Architecture Concept

CIDE consists of four major components:

- **Host AI:** The central intelligence responsible for planning and coordination.
- **Agent Manager:** Handles agent registration, task assignment and execution.
- **Browser AI Connector:** Interacts with supported AI websites through the user's browser.
- **Monitoring Dashboard:** Displays tasks, agent statuses, progress and results.
